观澜首个公开版本，适用于 Windows x64。

- Rust + Tauri 2 桌面应用，支持兼容 OpenAI Chat Completions 的模型服务。
- 流式对话、文件读写、命令执行、审批、计划和会话保存。
- 模型列表获取与关键词筛选。
- Material 3 界面，可切换玻璃与纯色材质。
- 修复多轮工具调用时重复显示“正在思考”的问题。

下载 `Guanlan_0.1.7_x64-setup.exe` 安装，或直接运行 `Guanlan_0.1.7_x64.exe`。

安装包和便携版由 GitHub Actions 从本版本源码构建，校验值见 `SHA256SUMS.txt`。
